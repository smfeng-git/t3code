# T3 Code

## Register
Product: a desktop, web and mobile interface for coding agents.

## Users and purpose
Developers manage coding conversations across providers, projects and local or remote environments. This customization serves a Windows and WSL workflow sharing Pi Web conversations.

## Design principles
Preserve the existing T3 tokens, typography, keyboard navigation and accessible controls. Prefer compact, familiar navigation. Titles are the primary information; repeated project names and incidental provider details should not dominate conversation lists. Keep environment scope visible and reversible. Avoid decorative animation, added card layers and hidden filtering.

## Scope
Reuse existing collapsible project folders and compact rows. Add persistent environment filtering alongside project filtering, covering search and settled threads. Do not change conversation contents or the mobile native UI.
