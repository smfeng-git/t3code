### 安装包与启动工具不是同一个交付物

上述下载项**不包含本地新写的 `Start.cmd` 一键启动工具**。本目录也不是安装包。已接入共享后端的用户先沿用现有启动方式；全新环境仅安装 T3，不能自动获得 Codex/Pi Web 共享接入。

新版启动工具目前尚未作为匹配的下载包交付，也未完成与本次安装包的实机联合验收。未拿到完整工具时，请先验证程序安装和登录，不要寻找不存在的 `Start.cmd`。

| 你要使用的功能                  | 需要准备                                                                 |
| ------------------------------- | ------------------------------------------------------------------------ |
| Windows 上 Codex 和 T3 共享聊天 | 定制 T3、已登录的 Codex App、Node.js 22+、Python 3.11+、完整接入工具目录 |
| Pi Web 和 T3 共享聊天           | 定制 T3 后端、已适配共享接口的 Pi Web、该环境的 Pi                       |
| 手机看同一份会话                | 先完成以上任一项，再将手机连接到自己的 T3 环境                           |

**只用 Codex 不需要装 Pi Web 或 WSL；只用 Pi 不需要 Codex 启动工具。**

## 安装后先验证

先按 [下载、安装与验证](SETUP.md#下载安装与验证) 检查程序能否安装、登录和连接自己的环境。仅验证手机浏览器新增功能，不需要配置 Codex 共享启动器。

## 已取得新版工具的用户：Windows Codex 接入

以下仅适用于提供方另外交付了完整新版工具目录的测试用户，**不是上述 Artifacts 下载后的默认步骤**；联合验收尚未完成。

1. 安装定制 T3、Codex App，先在 Codex 中登录；安装 [Node.js](https://nodejs.org/) 22+ 和 [Python](https://www.python.org/downloads/windows/) 3.11+（勾选 Add python.exe to PATH）。将本目录完整放到固定的可写位置，不要只复制 CMD 文件。
2. 双击 **`Start.cmd`**。工具自动查找程序、准备并打开 Codex、T3；找不到或有多个候选时才提示选择，之后会记住，不必编辑 JSON。
3. 按窗口显示的两项路径，在 T3 的 Codex 设置里连接一次。详细位置见 [首次接入](SETUP.md#codex-首次接入另需新版工具)。填好后在启动窗口确认，之后不再重复显示设置步骤；以后每天只需双击 `Start.cmd`。

首次启动需 Windows 自带的 .NET Framework C# 编译器；若缺失，请让提供接入包的人补齐环境或提供匹配的已编译适配器。启动器不自动下载或安装依赖。

## 使用时记住两件事

- 使用期间保持 **Codex App 打开**；启动窗口可以关闭。退出 Codex 前先结束 T3 中的任务。
- 请在**已有同一会话**中续聊。T3 新建会话自动出现在 Codex 侧栏目前仍有缺口，不要把“侧栏没出现”误认为所有同步都失败。

Pi 接入、手机连接、验证和故障恢复请看 [使用指南](SETUP.md)。
