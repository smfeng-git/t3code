# 验证清单

## 本次交付检查

T3 补丁从已验证提交导出；检查补丁能应用到固定基线，且文件与目标提交一致。交付不含历史工作区或真实用户配置。连接桥 Node 语法检查、启动器 Python 编译与隔离配置检查通过后才打包。

Pi Web 补丁来自现有集成附件；未在干净上游 checkout 验证其全部依赖。Windows 通用启动器未启动真实账号、未修改本机安装。预览安装包的构建证据以对应 GitHub Actions 任务为准；手机真机与全部 provider 交互仍需接收者验证。

## 接收者必须验证

1. 使用独立测试会话，Pi Web → T3 和 T3 → Pi Web 各发一条消息，只执行一次。
2. 新目录、新会话、Pi fork、标题修改可以发现；首次历史 Settled，后续新会话活跃；重启无重复。
3. Codex 两端同一会话双向文字可见；再验证真实工具、审批、停止与重连。
4. 手机连接正确环境，刷新后看到相同最终消息。
5. 侧栏环境筛选、项目筛选和 Settled 范围一致。
6. 关闭应用后停止共享启动器；普通模式恢复可用，历史保留。

## 不承诺的行为

- Pi 外部输出逐字直播、破坏性分支替换和删除双向镜像。
- 所有外部 Codex 运行都变成 T3 可控制的任务。
- 任意 Codex App/Pi Web/T3 版本组合兼容。
- 原版手机新增侧栏控件或网页批注。
- 安装源码补丁等于已经发布可用安装包。
