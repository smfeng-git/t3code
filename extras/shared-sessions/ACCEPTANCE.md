## 接收者必须验证

1. 使用独立测试会话，Pi Web → T3 和 T3 → Pi Web 各发一条消息，只执行一次。
2. 新目录、新会话、Pi fork、标题修改可以发现；首次历史 Settled，后续新会话活跃；重启无重复。
3. Codex 两端同一会话双向文字可见；再验证真实工具、审批、停止与重连。
4. 手机连接正确环境，刷新后看到相同最终消息。
5. 侧栏环境筛选、项目筛选和 Settled 范围一致。
6. 关闭应用后停止共享启动器；普通模式恢复可用，历史保留。
